🛡️ Firewall Chrome Extension  
📌 About  
This is a Chrome extension designed to improve browser security and privacy by acting like a firewall for web activity. It helps users block harmful websites, suspicious requests, ads, trackers, and unwanted content while browsing. The goal of this project is to provide a safer, faster, and more secure browsing experience.

⚙️ Tech Stack  
JavaScript, HTML, CSS, Chrome Extension APIs

🚀 Features  
Blocks harmful and suspicious websites  
Prevents trackers and unwanted ads  
Enhances browser privacy and security  
Lightweight and fast performance  
Easy-to-use interface  
Works directly inside Chrome browser  

📂 How to Run  
Go to: chrome://extensions/  
Enable Developer Mode  
Click on “Load unpacked”  
Select the project folder (which contains manifest.json)  
The extension will be added to Chrome
